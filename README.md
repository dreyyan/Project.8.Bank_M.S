**CashGO+** is a basic, user-friendly banking management system designed solely for educational purposes and to gain programming experience.

The purpose of CashGO+ is to simulate simple banking operations such as deposits, withdrawals, and account detail management. This system utilizes a straightforward menu-based interface, ensuring ease of use while practicing core programming concepts such as input validation, data handling, and functional decomposition.

While CashGO+ is not intended for real-world banking and does not use actual financial data, it provides an excellent foundation for learning the logic and flow of basic transaction management systems.

**FEATURES**  
✅ Deposit money to your account  
✅ Withdraw funds with balance validation  
✅ View account details instantly  
✅ Edit account holder information  
✅ User-friendly text-based interface
